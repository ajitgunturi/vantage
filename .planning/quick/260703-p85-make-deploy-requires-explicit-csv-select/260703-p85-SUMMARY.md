# Summary: make deploy requires explicit CSV selection

## What was built

`make deploy` now demands an explicit DCGM telemetry CSV — no silent demo data can reach a
deployed cluster — and the redundant committed fixture is gone.

- **Makefile `deploy`** is a recipe (was a bare prereq chain): resolves `CSV=<path>` → prompts on
  a TTY when omitted → fails loudly with `Usage: make deploy CSV=/path/to/your.csv` when scripted
  → validates the file exists and is readable → stages it to `build/.deploy/dcgm_metrics.csv`
  (inside the Docker build context, so any on-disk path works) → runs
  `$(MAKE) docker DEPLOY_CSV=... && $(MAKE) kind-load && $(MAKE) helm-install` → always cleans up
  `build/.deploy/`.
- **Explicit `docker-streamer` target** (overrides `docker-%`, still a prereq of `docker`) passes
  `--build-arg DEPLOY_CSV=...` only when set.
- **`build/streamer.Dockerfile`**: `ARG DEPLOY_CSV=` is the ONLY bake path. The
  `dcgm_metrics_*.csv` glob and the fixture fallback are removed. No-arg builds produce a CSV-less
  image (dev/test flows mount `testdata/fixture.csv` at runtime — compose/e2e unchanged).
- **Deleted `build/fixture/dcgm_metrics.csv`** — `testdata/fixture.csv` is the single test fixture.
- **`.dockerignore`**: root-level `dcgm_metrics_*.csv` excluded (1.1MB context trim for all five
  images); `build/.deploy/` stays in-context for the deploy bake. **`.gitignore`**: `build/.deploy/`.
- **Docs**: README "Bring your own CSV" section (evaluator-facing), Make-commands table row,
  `docs/development.readme.md` deploy workflow, `docs/streamer.readme.md` CSV-in-kind section,
  streamer chart configmap header comment.

## Verification (all executed live)

| Check | Result |
|---|---|
| `make deploy </dev/null` (non-TTY, no CSV) | exits non-zero with usage text |
| `make deploy CSV=/no/such/file.csv` | "ERROR: CSV not found or not readable", aborts pre-build |
| `make docker-streamer DEPLOY_CSV=<marker>` | marker file extracted verbatim from image `/data/dcgm_metrics.csv` |
| `make docker DEPLOY_CSV=...` (deploy's exact sub-make) | all 5 images build; baked CSV byte-identical to source (`cmp`) |
| `make docker-streamer` (no arg) | builds; image contains NO `/data/dcgm_metrics.csv` |
| `rg build/fixture` (outside .planning/.claude) | zero references |
| No script invokes `make deploy` non-interactively | soak.sh / smoke-05 only *assume* it ran (guard messages) |

Not run (needs live cluster, human check): full `make deploy CSV=...` through kind-load +
helm-install. The wiring it exercises beyond the above is `kind-load`/`helm-install`, both unchanged.

## Decisions

- No-arg streamer builds succeed as **CSV-less images** rather than failing: `make docker` must
  keep working for compose/e2e (runtime mount), and a direct helm install of a CSV-less image
  crashloops loudly (streamer hard-fails on missing CSV) — intentionality is preserved.
- Owner directive 2026-07-03 superseded the original "keep fixture fallback for dev/test targets"
  requirement — fixture deleted outright.
