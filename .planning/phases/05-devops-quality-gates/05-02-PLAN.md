| Helm values → running pods | DB credentials flow from values.yaml into Deployment/Job env |
| Bitnami OCI registry → local chart cache | postgresql chart tgz pulled from oci://registry-1.docker.io/bitnamicharts |
| in-cluster service-to-service | gRPC/HTTP/Postgres traffic between pods over ClusterIP (no TLS in kind) |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-05-03 | Elevation of Privilege | in-memory MQ broker | high | mitigate | mq sub-chart hardcodes replicas: 1 + strategy: Recreate (D-04) — prevents multi-replica split-brain of the non-replicable in-memory broker; values.yaml cannot raise replicas |
| T-05-04 | Information Disclosure | DB password in values.yaml | medium | accept | LOCAL DEV / kind only, no remote exposure — same precedent as docker-compose.yml; documented as dev-only. Production would use a Kubernetes Secret + valueFrom.secretKeyRef (out of v1 scope) |
| T-05-05 | Elevation of Privilege | migration Job DB privileges | low | accept | Migrate runs with full DB privileges — acceptable for dev/local; production would use a migration-scoped user (out of v1 scope) |
