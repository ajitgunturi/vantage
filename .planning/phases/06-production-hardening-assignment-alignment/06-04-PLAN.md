<objective>
Give the streamer an HTTP health listener (`/healthz` + `/readyz`) on a new env-configurable port so
Kubernetes probes have a target (OBS-01, finding F-02). Expose readiness via a `Runner` wrapper
without breaking the existing `Stream`/`Run` seams that the test suite depends on.

Purpose: streamer and collector currently expose no HTTP surface — Helm probes (Plan 06) need one.
Output: `streamer.Runner` with `IsReady()`, `Config.HealthAddr` (STREAMER_HEALTH_ADDR, default
:9000), and a health goroutine in the streamer main.

## Phase Goal (MVP framing)

**As an** operator, **I want to** probe the streamer's health over HTTP, **so that** Kubernetes can
gate the pod on whether it is actually streaming to the MQ. After Task 2 a probe against :9000/readyz
flips to 200 once the first record is produced.
</objective>
