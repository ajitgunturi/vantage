<objective>
Replace stdlib `log` with structured `log/slog` (JSON handler, level via env, per-service
`service` attribute) across all four services plus the migrate binary and the two internal
service packages, behind a shared `pkg/logger` helper (OBS-02, finding F-08).

Purpose: "Clear logging and error handling" is a graded assignment bonus. Structured logs also
improve diagnostic clarity for every subsequent Phase-6 slice; doing this first (no interface
changes) keeps later diffs readable.
Output: `pkg/logger.New(service) *slog.Logger`; all 27 `log.*` call sites migrated; DSN-never-logged
invariant preserved.

## Phase Goal (MVP framing)

**As a** grader/operator, **I want to** read every service's logs as leveled JSON with a service
tag, **so that** I can filter and correlate events across the pipeline without secrets leaking.

This plan refines an existing capability (every service already runs and logs): it upgrades the log
surface end-to-end so an operator observes structured output from every binary after this task.
</objective>
